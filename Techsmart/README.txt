TECHSMART DEMO WEBSITE
======================

FILES
- index.html       Homepage
- shop.html        Product catalogue
- repairs.html     Repair selection and WhatsApp booking form
- about.html       About page
- contact.html     Contact page
- css/style.css    All styling and responsive layout
- js/main.js       Theme toggle, mobile menu, shop search, repair WhatsApp form

HOW TO OPEN
1. Extract the TechSmart folder.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Use the navigation links to visit the other pages.

IMPORTANT BEFORE USING FOR A REAL BUSINESS
- Replace the sample WhatsApp number 254700000000 in js/main.js and the links in the HTML files.
- Replace sample address, phone number, product names, prices and stock details.
- Replace generic stock photos with verified product photos. Some images are illustrative and may not show the exact model named.
- The repair form opens WhatsApp; it does not save bookings in a database.
- This version does not yet have a real shopping cart, checkout, customer accounts, admin dashboard, inventory database or M-Pesa payments. Those need JavaScript plus backend/database/payment integration.
- Product information is currently written directly in HTML. A future admin dashboard will require a backend and database so the shop owner can edit products without editing code.

IMAGE NOTE
Images are loaded from Unsplash over the internet, so they need an internet connection. For a real client website, use images the business has permission to use.
